# Управление

Актуально для **v0.17.0** (схема ТЗ ч.2: ростер, непрерывная прокладка, обязательный финальный взгляд, команда;
ТЗ ч.3: атака и навыки; ТЗ ч.4: стартовое меню и режим «Разработчик»).

## Стартовое меню

| Кнопка | Что делает |
|---|---|
| **▶ Играть** | тактический бой на карте, выбранной в списке «Карта» (встроенные и ваши сохранённые) |
| **✎ Разработчик** | каталог контента: карты, юниты, навыки, типы гексов (подробно — `docs/EDITOR_GUIDE.md`) |
| **Выход** | закрыть игру |

В бою «← Главное меню» (в левой панели) спрашивает подтверждение: бой закрывается, объекты библиотеки не меняются.
Esc в окне подтверждения — «Остаться».

## Режим «Разработчик» (каталог)

| Действие | Управление |
|---|---|
| Выбрать категорию | кнопки слева: Карты, Юниты, Навыки, Гексы |
| Выбрать объект | клик по строке списка; свойства, ссылки и проверка — справа |
| Поиск / сортировка | поле поиска (название, ID, описание); список «По названию / дате / ID»; «↓» — обратный порядок |
| Дублировать | «Дублировать» — копия с новым ID (в том числе встроенного 🔒 объекта) |
| Переименовать | «Переименовать» → новое название → «Сохранить» (ID и ссылки не меняются) |
| Удалить | «Удалить» → подтверждение; объект, который используют другие: диалог с их списком → выбрать замену и «Заменить ссылки и удалить» или «В архив» (с v0.26.0) |
| Вернуть из архива | выбрать объект с «🗄» → «Вернуть из архива» в подробностях справа |
| Защита A юнита | «Сопротивления и защита» → в строке типа поле «A» (очки) рядом с «R, %» → Enter (с v0.27.0) |
| Вид и теги | «Происхождение и теги» → «Дерево видов» / «Теги»; юнит → «Особенности» → «Вид», «＋ Добавить тег», «Стая» (с v0.29.0) |
| Пассив юнита | «Особенности» → «Шаблон пассива» → «＋ Добавить пассив» → поля карточки → Enter (с v0.28.0) |
| Правила боя карты | редактор карт → «Карта» → «Правила боя» (K защиты; свои правила — «Механики» → «Правила боя») |
| Сторона внезапности на рисунке | «Правила боя» → шестиугольник → щелчок по стороне → её шанс или «▶ Тест атаки с этой стороны» (с v0.31.0) |
| Проверка бросков | «Проверить на ударе» → «Проверить 100 событий» / «Сбросить тест»; правила боя → «▶ Проверить 1000 бросков» (с v0.31.0) |
| Тег многим юнитам | редактор тега → «Назначить юниту» → «＋ В список назначения» → «Назначить тег (N)» (с v0.31.0) |
| Внезапность и криты | «Механики» → «Правила боя» → набор → «Внезапный удар по стороне цели», «Криты и сверхкриты»; шанс юнита — «Атака и навыки» → «Шанс крита» (с v0.30.0) |
| Новый тип прямо из поля | в списке «Тип урона» любого редактора — «＋ Новый тип урона…» → основа → настроить → «Сохранить» → «← Назад»: тип выбран в поле |
| Отменить / вернуть | **Ctrl+Z** / **Ctrl+Y** или **Ctrl+Shift+Z**, кнопки «↶ Отменить» / «↷ Вернуть» |
| Снять выделение | **Esc** |
| Проверить библиотеку | «Проверить всё» — итог в панели сообщений |
| Экспорт | выбрать объект → «Экспорт…» → «Объект .json» или отметить объекты и «Пакет .hxp» (файлы — в папке экспорта) |
| Импорт | «Импорт…» → путь или имя файла из папки экспорта (или «Обзор…») → «Показать» → выбрать действие для каждого объекта → «Установить» |
| Назад в меню | «← Меню» |

## Выставление из ростера (нижняя панель)

| Шаг | Действие |
|---|---|
| 1 | Зажать **ЛКМ на карточке** оперативника внизу экрана и тянуть на карту: разрешённые клетки (база и зона выставления) зелёные, остальные — мягко-красные, под курсором — полупрозрачный юнит. |
| 2 | Отпустить на **зелёной** клетке → юнит появляется, и **сразу** от него тянется белая стрелка (клик по юниту не нужен). |
| 3 | Дальше как обычный приказ: клики → ТД1, ТД2…, клик у ребра последней ТД — взгляд; или сразу клик **у ребра клетки юнита** — взгляд без движения. |

- Отпустить на красной клетке или над панелью, нажать ПКМ или Esc → карточка возвращается в ростер, юнит не расходуется.
- Пока взгляд не задан, юнит стоит с жёлтым «?» и ничего не делает. Отменили стрелку — он ждёт; клик по нему (или по его
  карточке) снова открывает стрелку.
- Клик по карточке уже выставленного оперативника выбирает его.

## Приказ одному юниту

| Шаг | Действие |
|---|---|
| 1 | Зажать **ЛКМ на юните** и протянуть к зелёной клетке, отпустить → **ТД1**. Режим прокладки продолжается. |
| 2 | Белая стрелка сама тянется от ТД1 к курсору. **Клик ЛКМ** по зелёной клетке → ТД2, затем ТД3… |
| 3 | Навести курсор **у ребра** последней ТД (не в центр) — появится белая мини-стрелка взгляда. **Клик** → приказ принят целиком. |

- Без ТД: шаг 1 можно заменить выбором юнита (клик) и кликом **у ребра его клетки** → поворот на месте.
- Пока финальный взгляд не подтверждён, юнит ничего не делает — это черновик (ТД с янтарной каймой).
- Центр исходной клетки — нейтральная зона: клик там ничего не подтверждает.
- Продолжить уже принятый маршрут: зажать ЛКМ на **последней** ТД юнита и протянуть.

## Команда (несколько юнитов одним приказом)

| Шаг | Действие |
|---|---|
| 1 | Нажать карточку **«Команда»** справа в нижней панели. |
| 2 | **Клик по своему юниту** — он капитан (белый ромб). Клики по другим своим юнитам — участники (голубые кольца). От каждого тянется голубая стрелка к курсору. |
| 3 | **Клик по зелёной клетке** — КТД1: капитан встанет в неё, остальные — на соседние клетки (стрелки показывают куда). Дальше клики — КТД2, КТД3… |
| 4 | **Клик у ребра последней КТД** — взгляд капитана; приказ принят, команда идёт. |

- Зелёные клетки — вокруг них помещается вся команда; красные — капитан не дойдёт или мест рядом не хватает.
- Повторный клик по участнику ничего не меняет; капитан — всегда первый выбранный. До 7 участников.
- ПКМ / Esc / повторное нажатие «Команда» — выход без приказа; ПКМ по КТД — удалить её и следующие.
- Спутники смотрят туда же, куда капитан, или на 60° в сторону — у ребра последней КТД видно, кто куда будет смотреть.
- Команда идёт по КТД синхронно: пришедшие ждут остальных у каждой КТД. Если свой стоит на пути, он отходит в сторону.
- Взгляд у стены: можно кликать у ребра, даже если соседнее препятствие на экране закрывает край клетки.

## Атака врага

| Действие | Результат |
|---|---|
| Протянуть белую стрелку от юнита (или от очередной ТД) **на врага** и отпустить / кликнуть | приказ атаки вместо ТД: юнит сразу смотрит на цель, проходит поставленные ТД, подходит на соседнюю клетку и бьёт 3 раза/с |
| Наведение стрелки на врага | оранжевая стрелка и кольцо цели (не красная «запрещённая» клетка) |
| Новый приказ юниту / ПКМ по его ТД | атака отменяется |

- Финальный взгляд для атаки не выбирается — его задаёт цель. Урон 10 и дальность 1 — временные значения прототипа.
- Если подойти некуда — «цель недостижима», юнит ждёт. Погибший юнит снимается с карты.
- Для проверки: «Мишень врага (T)» — клик по клетке ставит неподвижного врага; «Стенд» — четыре мишени.

## Навык «Линейный удар»

С v0.18.0 у юнита может быть несколько навыков (редактор навыков и юнитов): кнопка **R** и первая кнопка в панели —
первый навык юнита, в меню ТД — все его навыки по порядку. Навык с несколькими попаданиями — одно действие: юнит стоит в
точке до последнего удара, потом идёт дальше; цели — те, кто в клетке в момент удара.

| Шаг | Действие |
|---|---|
| 1 | Выбрать своего юнита, нажать «✦ Линейный удар (R)» или **R**. |
| 2 | Повести курсор в сторону удара: две клетки перед юнитом в этом направлении подсвечиваются **серым**, красная стрелка показывает направление. |
| 3 | **ЛКМ** — удар: 20 урона каждому врагу, который стоит в этих клетках в момент удара. **ПКМ/Esc** — отмена прицеливания. |

- На паузе удар запоминается и происходит после её снятия; идущий юнит бьёт, дойдя до центра клетки.
- Союзники не получают урона; клетки за краем поля не учитываются.

## Навык в точке маршрута (ТД)

| Шаг | Действие |
|---|---|
| 1 | Проложить маршрут как обычно: от юнита → ТД1, клики → ТД2, ТД3… (без лишних меню). |
| 2 | **Коротко кликнуть ЛКМ по центру маркера ТД** (не тянуть) — рядом появится меню с иконкой «✦ Линейный удар». ТД не добавляется. |
| 3 | Клик по иконке — от ТД тянется **красная стрелка**; две клетки в выбранном направлении **от этой ТД** подсвечиваются серым. |
| 4 | **ЛКМ** — направление принято: у ТД появляется красный шестиугольник «✦1». Дальше — следующие ТД или клик у ребра последней ТД (финальный взгляд), как обычно. |

- Работает и в черновике (навык применяется вместе с приказом), и на уже принятом маршруте выбранного юнита
  (короткий клик по его ТД). На паузе ничего не происходит до её снятия.
- Юнит доходит до ТД, поворачивается в сторону удара, бьёт один раз (20 урона врагам в двух клетках в этот момент) и сам
  идёт дальше. На последней ТД после удара поворачивается к выбранному финальному взгляду.
- Одна ТД — один навык; повторное назначение заменяет прежний. «✕» в меню — убрать навык, ТД остаётся. Удаление ТД
  (ПКМ по ней) удаляет и её навык; навыки других ТД остаются.
- Перетаскивание от ТД по-прежнему меняет маршрут, клик у ребра последней ТД — по-прежнему финальный взгляд.
- Пока открыто меню ТД или выбирается направление навыка, зелёно-красная подсветка клеток скрыта (клик не ставит ТД);
  после отмены навыка она возвращается.

## Отмена

| Действие | Результат |
|---|---|
| **ПКМ** (не по ТД) или **Esc** во время прокладки | весь черновик отменён, принятые раньше приказы не меняются |
| Клик по красной клетке во время прокладки | то же — отмена черновика |
| Наведение на красную клетку | только показывает, что туда нельзя |
| **ПКМ по ТД черновика** | удалить её и все следующие ТД черновика |
| **ПКМ по принятой ТД** выбранного юнита | удалить её и все следующие из его маршрута |
| **ПКМ/Esc** при открытом меню ТД | закрыть только меню (клик мимо меню — тоже) |
| **ПКМ/Esc** при красной стрелке навыка | отменить только навык; следующая ПКМ — черновик маршрута |

## Цвета

| Что | Значение |
|---|---|
| Зелёные / красные клетки | можно / нельзя поставить ТД (препятствие, занято, изолировано) |
| Жёлтая клетка | исходная клетка: её сектора у рёбер — выбор финального взгляда |
| Белая толстая стрелка | приказ (поверх всех объектов); красная — нельзя; оранжевая с кольцом — атака врага |
| Полоска над юнитом | здоровье: зелёная — свои, красная — враги |
| Серые клетки, красная стрелка | область и направление навыка (не путать с зелёным/красным движения); ярче — прицеливание и ТД под курсором, бледнее — остальные назначенные |
| Красный шестиугольник «✦1» у ТД | в этой ТД назначен один навык; исчезает после удара |
| Голубые стрелки и маркеры | командный приказ: КТД капитана с номерами, маленькие шестиугольники — места спутников |
| Голубое кольцо / белый ромб | участник собираемой команды / капитан |
| Тонкая зелёная / тёмная линия | путь к курсору / рассчитанный маршрут |
| Белая мини-стрелка у ребра | взгляд юнита (на его клетке), предпросмотр сектора или сохранённый финальный взгляд (у последней ТД) |
| Жёлтый «?» над юнитом | выставлен из ростера, взгляд ещё не задан — юнит не активен |
| Карточка ростера | серая с зелёной рамкой — доступна; зелёная — тянется; жёлтая — ждёт взгляда; тёмная — на поле |

## Редактор карт

| Действие | Управление |
|---|---|
| Создать гекс | ЛКМ по пустому месту рабочей области (тип — «Новые гексы» в левой панели) |
| Выбрать гекс / снять выбор | ЛКМ по гексу / **Esc** |
| Удалить гексы | красная «✕ Удалить гексы» → клики отмечают гексы → **ещё раз** красная кнопка; **Esc** — выйти без удаления |
| Отменить / вернуть | **Ctrl+Z** / **Ctrl+Y** или **Ctrl+Shift+Z** |
| Сохранить | **Ctrl+S** или «Сохранить» |
| Масштаб / сдвиг | колесо мыши / средняя кнопка или **пробел** + ЛКМ и перетаскивание |
| Вид | «Вид: 60°» ↔ «Вид: сверху» |
| Тест | «▶ Тест карты» → бой на копии → «← Вернуться в редактор» |

## Редактор юнитов

| Действие | Управление |
|---|---|
| Изменить число | ввести значение и **Enter** (или перейти к другому полю); недопустимое — отклоняется с пояснением внизу |
| Навыки | «Добавить навык: поиск» → выбрать в списке → «＋ Добавить навык»; ↑/↓ — порядок (первый — кнопка R в бою), ✕ — убрать |
| Показать зону навыка | клик по названию навыка в списке |
| Тест | «▶ Тест юнита» → бой, юнит — карточка «Альфа» → «← Вернуться в редактор» |
| Сохранить / отменить | **Ctrl+S** / **Ctrl+Z**, **Ctrl+Y** |

На стартовом экране «Отряд» — из какого юнита сделаны пять карточек ростера в «Играть».

С v0.21.0 в редакторе юнита: «Тип урона обычной атаки», «Область обычной атаки», секция «Сопротивления» — число в процентах
и **Enter** (−500…+500, запятая или точка); недопустимое отклоняется с пояснением внизу.
С v0.22.0 — секция «Особые защиты и реакции»: поиск правила, выбор в списке, «＋ Добавить правило», ✕ — убрать; щиты —
«＋ Добавить щит», поля названия, прочности, принимаемого урона и порядка (**Enter**), «✕ Убрать щит».

## Редактор юнита: секции и «Сопротивления» (v0.24.0)

| Действие | Управление |
|---|---|
| Открыть секцию | щелчок по заголовку «▸ Основное / Атака и навыки / Сопротивления / Дополнительно» |
| Подтипы семейства | «▸ подтипы» под строкой семейства |
| Найти тип | поле «Поиск: тип, тег, семейство» → **Enter**; очистить — ✕ в поле |

## Редактор типов гексов
