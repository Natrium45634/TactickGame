# Управление

Актуально для **v0.2.0**.

| Действие | Управление | С версии |
|---|---|---|
| Узнать клетку под курсором | Навести мышь: клетка мягко подсвечивается, координаты, тип и юнит — в панели | v0.1.0 |
| Выбрать юнита | Короткий щелчок ЛКМ по юниту (по корпусу или по его клетке) | v0.2.0 |
| Снять выделение | Щелчок ЛКМ по пустой клетке или вне поля | v0.2.0 |
| Появление на базе | Кнопка «База» (первая свободная клетка базы) | v0.2.0 |
| Появление в зоне на краю | Кнопки «Северный», «Восточный» (первая свободная клетка зоны) | v0.2.0 |
| Прямое выставление | Кнопка «Выставить на клетку (P)» или клавиша **P**, затем щелчок по зелёной клетке | v0.2.0 |
| Выйти из режима выставления | **Esc** или щелчок **ПКМ** | v0.2.0 |
| Повернуть выбранного юнита (отладка) | **Q** — против часовой, **E** — по часовой (на 60°) | v0.2.0 |
| Закрыть игру | Закрыть окно (Alt+F4) | v0.1.0 |

Заметки:
- Небольшое дрожание руки при щелчке (до 8 px) не превращает щелчок в перетаскивание.
- При невозможном размещении (занято, препятствие, вне поля, зона заполнена) выводится сообщение,
  существующие юниты не удаляются и не перемещаются.
- В режиме выставления все 120 клеток подсвечены: зелёные — можно поставить, красные — нельзя.

Запланировано ТЗ: протягивание стрелок ЛКМ и точки движения, поворот без движения, Esc/ПКМ — отмена текущей
стрелки (v0.3.0), подсветка достижимости и движение (v0.4.0), пробел — тактическая пауза (v0.5.0).

## Аргументы командной строки (отладка)

Указываются после `--`, например `HexTactics.exe -- --hx-script="spawn:base;click:0,4" --hx-screenshot=shot.png`.
См. `docs/ARCHITECTURE.md`, раздел «Автоматизация».
