# Управление

Актуально для **v0.5.0** (этап 1 завершён).

| Действие | Управление | С версии |
|---|---|---|
| Тактическая пауза / продолжить | **Пробел** или кнопка «Пауза» в панели. На паузе можно выбирать юнитов, протягивать стрелки и строить цепочки ТД | v0.5.0 |
| Узнать клетку под курсором | Навести мышь: клетка мягко подсвечивается, координаты, тип и юнит — в панели | v0.1.0 |
| Выбрать юнита | Короткий щелчок ЛКМ по юниту (по корпусу или по его клетке) | v0.2.0 |
| Снять выделение | Щелчок ЛКМ по пустой клетке или вне поля | v0.2.0 |
| Создать ТД1 (новый маршрут) | Зажать ЛКМ на юните, протянуть стрелку к клетке, отпустить. Старая невыполненная очередь заменяется | v0.3.0 |
| Добавить следующую ТД | Зажать ЛКМ на **последней** ТД юнита, протянуть, отпустить | v0.3.0 |
| Повернуть юнита без движения | Зажать ЛКМ на юните (у которого нет ТД), сделать короткий жест в нужную сторону **внутри его клетки**, отпустить в этой же клетке | v0.3.0 |
| Отменить текущую стрелку | **Esc** или **ПКМ** во время протягивания — уже созданные ТД не меняются | v0.3.0 |
| Выбрать ТД | Короткий щелчок ЛКМ по маркеру ТД | v0.3.0 |
| Поставить / убрать препятствие (отладка) | Кнопка «Препятствие (O)» или **O**, затем щелчок по клетке; Esc / ПКМ — выход | v0.4.0 |
| Появление на базе / в зоне | Кнопки «База», «Северный», «Восточный» | v0.2.0 |
| Прямое выставление | Кнопка «Выставить на клетку (P)» или **P**, затем щелчок по зелёной клетке; Esc / ПКМ — выход | v0.2.0 |
| Повернуть выбранного юнита (отладка) | **Q** / **E** — на 60° против / по часовой | v0.2.0 |
| Закрыть игру | Закрыть окно (Alt+F4) | v0.1.0 |

## Подсказки во время протягивания

| Цвет | Значение |
|---|---|
| Жёлтая заливка клетки | исходная клетка стрелки (юнит или последняя ТД); жест внутри неё = поворот |
| Зелёные клетки (все 120 подсвечены) | достижимы и свободны — здесь можно поставить ТД |
| Красные клетки | препятствие, занято другим юнитом или изолировано (пути нет, даже если клетка свободна) |
| Белая стрелка | отпускание создаст ТД; красная стрелка — нельзя |
| Тонкая зелёная линия | кратчайший путь к клетке под курсором (огибает препятствия) |
| Жёлтая стрелка | отпускание повернёт юнита в показанную сторону |
| Серая стрелка | отпускание ничего не изменит |

- Небольшое дрожание руки (до 8 px) не начинает протягивание.
- Поворот засчитывается только при отпускании в исходной клетке на расстоянии ≥ ¼ размера гекса от центра.
- Юнит идёт по цепочке со скоростью 2 гекса/с; тонкая белая линия показывает его рассчитанный маршрут.
- Если пути к очередной ТД больше нет, юнит останавливается (красный «!»), приказы сохраняются, причина — в панели.
- Новое протягивание из идущего юнита начинается с клетки, в которую он сейчас шагает.
- На паузе игровое время стоит; приказы, отданные на паузе, начинают исполняться после её снятия без скачка.

## Аргументы командной строки (отладка)

Указываются после `--`, например
`HexTactics.exe -- --hx-script="spawn:base;drag:0,4>3,2" --hx-screenshot=shot.png`. См. `docs/ARCHITECTURE.md`, «Автоматизация».
