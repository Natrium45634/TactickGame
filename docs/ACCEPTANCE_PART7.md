# Приёмка ТЗ ч.7 (§12): где проверен каждый пункт

Состояние на **v0.39.0** — план части 7 (D-150) выполнен, все пункты M7-01…M7-60 приняты. «Тест» — автотест `dotnet test` (класс.метод), «Сценарий» — регрессия Windows-сборки
`tools/verify_release.ps1` (`$RegressionScenarioV3x`, второй запуск `$PersistenceScenarioV3x`, чистая установка
`$CleanImportScenarioV3x`). План версий части 7 — D-150 (v0.32.0–v0.39.0); пункт считается принятым только с тестом и, где он
касается интерфейса, шагом сценария. Все сценарии частей 1–6 запускаются в каждой версии.
