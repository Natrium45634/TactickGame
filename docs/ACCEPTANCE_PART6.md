# Приёмка ТЗ ч.6 (§12): где проверен каждый пункт

Состояние на **v0.26.0**. «Тест» — автотест `dotnet test` (класс.метод), «Сценарий» — регрессия Windows-сборки
`tools/verify_release.ps1` (`$RegressionScenarioV2x`, второй запуск `$PersistenceScenarioV2x`, чистая установка
`$CleanImportScenarioV2x`). Пункты механик следующих версий плана (D-143) отмечены версией, в которой они появятся; пункт
считается принятым только с тестом и, где он касается интерфейса, шагом сценария. Все сценарии частей 1–5 запускаются в
каждой версии.
