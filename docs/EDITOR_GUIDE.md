# Руководство по режиму «Разработчик»

Режим «Разработчик» — встроенная мастерская игрового контента (ТЗ ч.4). Он пользуется тем же ядром и той же
симуляцией, что и «Играть»: в редакторах меняются **данные**, а не правила. Описание форматов — `docs/CONTENT_FORMAT.md`.

## Запуск

Запустите игру → кнопка **«Разработчик»**. Возврат — **«← Меню»** в правом верхнем углу (данные не теряются).

## Каталог

```
┌ HexTactics · Разработчик   Объектов: 11 · своих: 1        [↶ Отменить] [↷ Вернуть] [← Меню] ┐
├ Категории ┬ Список выбранной категории                                  ┬ Свойства объекта ┤
│ Карты   1 │ [Поиск…………………………] [По названию ▾] [↓]                       │ имя, ID, ревизия │
│ Юниты   1 │ Название │ Тип / описание │ ID │ Изменён │ Ред. │ Проверка        │ ссылки           │
│ Навыки  1 │ 🔒 …     │ …              │ …  │ …       │ 1/с1 │ ок              │ используется в   │
│ Гексы   7 │ [＋ Создать][Открыть][Дублировать][Переименовать][Удалить]…     │ проверка         │
├───────────┴─────────────────────────────────────────────────────────────┴──────────────────┤
│ Сообщения и проверки                                                                         │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **Категории** слева строятся из реестра: «Карты», «Юниты», «Навыки», «Гексы». Новые категории (статусы, волны…)
  появятся здесь, когда будут реализованы их механики.
- **Список**: название, тип/краткое описание, ID, дата изменения, ревизия/версия схемы, результат проверки. Поиск — по
  названию, ID и описанию; сортировка — по названию, дате, ID (кнопка «↓» — обратный порядок).
- 🔒 — встроенный объект игры: только чтение, его можно **дублировать** — копия получит новый ID и станет вашей.
- **Переименовать** меняет только название — ID и все ссылки остаются.
- **Удалить** — с подтверждением. Объект, на который ссылаются другие (например, навык юнита), удалить нельзя — каталог
  покажет, кто его использует. Удалённое возвращается кнопкой «Отменить».
- **Отменить / Вернуть** (Ctrl+Z, Ctrl+Y или Ctrl+Shift+Z) — для дублирования, переименования и удаления.
- **Проверить всё** — проверка всех объектов и ссылок; итог и ошибки — в панели сообщений внизу.
- **Создать / Открыть** — редакторы карт (v0.16.0) и юнитов (v0.17.0); редакторы навыков (v0.18.0) и типов гексов (v0.19.0)
  подключатся следующими версиями. **Импорт / Экспорт** — v0.20.0.
- Если в прошлый раз работа не была сохранена, при входе в режим разработчика появится «Восстановить черновик?».

## Редактор карт (v0.16.0)

«Карты» → **«＋ Создать»** (новая карта) или выбрать карту → **«Открыть»** (встроенная сохранится как ваша копия).

1. Поле — рабочая область 12 × 10: бледные контуры с координатами `col,row` — это **ещё не гексы**.
2. **ЛКМ по пустому месту** — появляется гекс типа, выбранного в «Новые гексы», и его настройки слева.
   **ЛКМ по гексу** — выбрать его. Esc — снять выделение.
3. Слева — **тип** гекса (обычный, высокий, базы, препятствие, зона выставления, край/зона появления, свои типы),
   высота, номер и название зоны появления, **тестовая точка** маршрута, комментарий. Проходимость и выставление
   определяются типом.
4. **Красная кнопка «✕ Удалить гексы»**: первое нажатие — режим выбора, клики отмечают гексы (счётчик на кнопке);
   **второе нажатие** удаляет все отмеченные. Esc или «Отмена» — выйти, ничего не удаляя. **Ctrl+Z** вернёт удалённые.
5. Вкладка **«Карта»**: название, описание, название базы, размер области («Применить размер»), сводка.
6. **«Проверить»** — ошибки и замечания в панели внизу; **«Сохранить»** (Ctrl+S) — только карту без ошибок.
7. **«▶ Тест карты»** — бой на временной копии (выставление, ТД/КТД, пауза); «← Вернуться в редактор» — назад.
8. **«← Каталог»** — при несохранённых изменениях спросит «Сохранить / Не сохранять / Отмена».

Камера: колесо — масштаб, средняя кнопка или пробел+перетаскивание — сдвиг, «Вид: 60° / сверху».
Сохранённая карта появляется в списке «Карта» на стартовом экране — её можно сразу играть.

## Где хранится ваш контент

`user://content/…` (Windows: `%APPDATA%\Godot\app_userdata\HexTactics\content`), путь показан внизу стартового меню.
Сохранение атомарное (временный файл → проверка → замена), удалённые объекты лежат в `backups/deleted`, журнал —
`logs/content.log`. Обновление игры эту папку не трогает.

## Редактор юнитов (v0.17.0)

«Юниты» → **«＋ Создать»** или **«Открыть»** (встроенный «Оперативник» сохранится как ваша копия).

- Слева — **характеристики**: максимум здоровья, скорость движения (гекс/с), скорость атак (удар/с), **сила атаки
  (Attack Power)** — урон одного удара, дальность, сторона. Значение применяется по Enter; недопустимое (отрицательное,
  ноль, текст вместо числа, дробное здоровье) отклоняется с пояснением внизу — ничего не портится.
- **Навыки** — ссылки на навыки библиотеки: найдите навык, «＋ Добавить навык», ↑/↓ — порядок (первый — кнопка R и меню
  ТД в бою), ✕ — убрать. Клик по названию показывает зону навыка на поле предпросмотра.
- **Внешний вид** — оттенок и размер модели (только вид: юнит занимает один гекс).
- Справа — **«В бою»**: урон за удар × удары в секунду, время перехода гекса, эффекты навыков; ниже — проверка.
- **«▶ Тест юнита»** — бой на карте «Прототип», ваш юнит — карточка «Альфа» ростера.
- Сохранённый юнит можно выбрать на стартовом экране в списке **«Отряд»**.
