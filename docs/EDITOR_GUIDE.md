# Руководство по режиму «Разработчик»

Режим «Разработчик» — встроенная мастерская игрового контента (ТЗ ч.4). Он пользуется тем же ядром и той же
симуляцией, что и «Играть»: в редакторах меняются **данные**, а не правила. Описание форматов — `docs/CONTENT_FORMAT.md`.

## Запуск

Запустите игру → кнопка **«Разработчик»**. Возврат — **«← Меню»** в правом верхнем углу (данные не теряются).

## Каталог

```
┌ HexTactics · Разработчик   Объектов: 11 · своих: 1        [↶ Отменить] [↷ Вернуть] [← Меню] ┐
├ Категории ┬ Список выбранной категории                                  ┬ Свойства объекта ┤
│ Карты   1 │ [Поиск…………………………] [По названию ▾] [↓]                       │ имя, ID, ревизия │
│ Юниты   1 │ Название │ Тип / описание │ ID │ Изменён │ Ред. │ Проверка        │ ссылки           │
│ Навыки  1 │ 🔒 …     │ …              │ …  │ …       │ 1/с1 │ ок              │ используется в   │
│ Гексы   7 │ [＋ Создать][Открыть][Дублировать][Переименовать][Удалить]…     │ проверка         │
├───────────┴─────────────────────────────────────────────────────────────┴──────────────────┤
│ Сообщения и проверки                                                                         │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **Категории** слева строятся из реестра: «Карты», «Юниты», «Навыки», «Гексы». Новые категории (статусы, волны…)
  появятся здесь, когда будут реализованы их механики.
- **Список**: название, тип/краткое описание, ID, дата изменения, ревизия/версия схемы, результат проверки. Поиск — по
  названию, ID и описанию; сортировка — по названию, дате, ID (кнопка «↓» — обратный порядок).
- 🔒 — встроенный объект игры: только чтение, его можно **дублировать** — копия получит новый ID и станет вашей.
- **Переименовать** меняет только название — ID и все ссылки остаются.
- **Удалить** — с подтверждением. Удалённое возвращается кнопкой «Отменить». Если объект используют другие (например,
  тип урона — навык и юнит), диалог (с v0.26.0) перечисляет их («юниты: Поджигатель») и предлагает:
  **«Заменить ссылки и удалить»** — выбрать совместимую замену (того же вида, у типа урона — той же стратегии) и
  переписать ссылки во всех пользователях разом; **«В архив»** — объект остаётся рабочим для тех, кто его уже использует,
  но в новых списках не предлагается (в каталоге — «🗄»). «Вернуть из архива» — кнопка в подробностях объекта справа.
- **Отменить / Вернуть** (Ctrl+Z, Ctrl+Y или Ctrl+Shift+Z) — для дублирования, переименования и удаления.
- **Проверить всё** — проверка всех объектов и ссылок; итог и ошибки — в панели сообщений внизу.
- **Создать / Открыть** — редакторы карт (v0.16.0), юнитов (v0.17.0), навыков (v0.18.0) и типов гексов (v0.19.0).
- Если в прошлый раз работа не была сохранена, при входе в режим разработчика появится «Восстановить черновик?».

## Редактор карт (v0.16.0)

«Карты» → **«＋ Создать»** (новая карта) или выбрать карту → **«Открыть»** (встроенная сохранится как ваша копия).

1. Поле — рабочая область 12 × 10: бледные контуры с координатами `col,row` — это **ещё не гексы**.
2. **ЛКМ по пустому месту** — появляется гекс типа, выбранного в «Новые гексы», и его настройки слева.
   **ЛКМ по гексу** — выбрать его. Esc — снять выделение.
3. Слева — **тип** гекса (обычный, высокий, базы, препятствие, зона выставления, край/зона появления, свои типы),
   высота, номер и название зоны появления, **тестовая точка** маршрута, комментарий. Проходимость и выставление
   определяются типом.
4. **Красная кнопка «✕ Удалить гексы»**: первое нажатие — режим выбора, клики отмечают гексы (счётчик на кнопке);
   **второе нажатие** удаляет все отмеченные. Esc или «Отмена» — выйти, ничего не удаляя. **Ctrl+Z** вернёт удалённые.
5. Вкладка **«Карта»**: название, описание, название базы, размер области («Применить размер»), сводка.
6. **«Проверить»** — ошибки и замечания в панели внизу; **«Сохранить»** (Ctrl+S) — только карту без ошибок.
7. **«▶ Тест карты»** — бой на временной копии (выставление, ТД/КТД, пауза); «← Вернуться в редактор» — назад.
8. **«← Каталог»** — при несохранённых изменениях спросит «Сохранить / Не сохранять / Отмена».

Камера: колесо — масштаб, средняя кнопка или пробел+перетаскивание — сдвиг, «Вид: 60° / сверху».
Сохранённая карта появляется в списке «Карта» на стартовом экране — её можно сразу играть.

## Где хранится ваш контент

`user://content/…` (Windows: `%APPDATA%\Godot\app_userdata\HexTactics\content`), путь показан внизу стартового меню.
Сохранение атомарное (временный файл → проверка → замена), удалённые объекты лежат в `backups/deleted`, журнал —
`logs/content.log`. Обновление игры эту папку не трогает.

## Редактор юнитов (v0.17.0)

«Юниты» → **«＋ Создать»** или **«Открыть»** (встроенный «Оперативник» сохранится как ваша копия).

- Слева — **характеристики**: максимум здоровья, скорость движения (гекс/с), скорость атак (удар/с), **сила атаки
  (Attack Power)** — урон одного удара, дальность, сторона. Значение применяется по Enter; недопустимое (отрицательное,
  ноль, текст вместо числа, дробное здоровье) отклоняется с пояснением внизу — ничего не портится.
- **Навыки** — ссылки на навыки библиотеки: найдите навык, «＋ Добавить навык», ↑/↓ — порядок (первый — кнопка R и меню
  ТД в бою), ✕ — убрать. Клик по названию показывает зону навыка на поле предпросмотра.
- **Внешний вид** — оттенок и размер модели (только вид: юнит занимает один гекс).
- Справа — **«В бою»**: урон за удар × удары в секунду, время перехода гекса, эффекты навыков; ниже — проверка.
- **«▶ Тест юнита»** — бой на карте «Прототип», ваш юнит — карточка «Альфа» ростера.
- Сохранённый юнит можно выбрать на стартовом экране в списке **«Отряд»**.

## Редактор навыков (v0.18.0)

«Навыки» → **«＋ Создать»** или **«Открыть»** (встроенный «Линейный удар» сохранится как ваша копия).

1. Поле — ровные гексы вокруг **базового юнита** с белым указателем взгляда. Новый навык — без клеток.
2. **ЛКМ по пустому гексу** — клетка входит в область и выбирается: слева её настройки. **ЛКМ по клетке** — выбрать её.
   Убрать клетку — «Убрать из области» или включить **«Ластик»** и кликнуть. Esc — снять выбор (настройки навыка).
3. **↺ / ↻** (Q / E) — повернуть юнита: рисунок поворачивается для всех шести направлений; клетки хранятся относительно
   взгляда, поэтому навык в бою бьёт туда, куда смотрит юнит (или куда указала красная стрелка). «Размер поля» — радиус.
4. Без выбранной клетки — **иконка** и **эффекты навыка**: их наследуют все клетки без своих эффектов. «Новый эффект» →
   «＋ Добавить эффект»: урон, лечение, бафф, дебафф, периодический.
5. Выбранная клетка: положение, **цвет и прозрачность** (только для вас — бой рисует зону серым), **«Свои эффекты
   клетки»**. Пока галочка снята, клетка наследует эффекты навыка; если поменять поле здесь, оно станет своим только для
   этой клетки — рядом появится «• … своё значение клетки» и кнопка **«↺ как у навыка»**.
6. Урон и лечение — фиксированное число или **% от силы атаки** (150 % = 1,5 × Attack Power, а не здоровье цели);
   **число попаданий** и **интервал** между ними в игровых секундах. Бафф/дебафф — характеристика, величина в процентах
   или фиксированная, длительность и что делать при повторе. Цели — враги, союзники, сам, все.
7. Справа — **итог каждой клетки** числами для выбранного юнита или своей силы атаки; ниже — проверка.
8. **«▶ Тест навыка»** — бой на «Прототипе»: навык первый у всех карточек ростера (кнопка R и меню ТД). Чтобы юнит в
   игре получил навык, добавьте его в редакторе юнитов («Навыки» → «＋ Добавить навык»).

## Редактор типов гексов (v0.19.0)

«Гексы» → **«＋ Создать»** или **«Открыть»** (встроенный тип сохранится как ваша копия).

1. **Свойства типа**: категория («особый (поверхность)» — для жгучих, целебных и т. п.), проходимость, **«Можно ставить
   ТД/КТД»** (если снять — через гекс можно пройти, но остановиться в ТД нельзя: он красный при прокладке маршрута).
2. **Внешний вид**: уровень (высота), цвет, **значок** до 4 символов — он рисуется на каждом гексе типа.
3. **Эффекты**: «Новый эффект» → «＋ Добавить эффект». **Периодический** по умолчанию — урон 5 HP за каждую игровую
   секунду, **пока юнит на гексе**; «Что» → «лечение» делает целебную поверхность (не выше максимума здоровья).
   Урон, лечение, бафф, дебафф срабатывают **при входе** или **при выходе**. «На кого действует» — все, только юниты
   игрока, только враги.
4. Справа — **правила типа словами** («за 2 с — 10 HP»). Считается гекс, в котором юнит числится (смена — когда тело
   пересекает границу), поэтому плавный поворот не «срежет» лишнего урона; на паузе ничего не меняется.
5. **«▶ Тест гекса»** — бой на «Прототипе», блок 2 × 3 гексов перед базой стал вашим типом.
6. **Сохранить** — тип появится в редакторе карт: «Тип для клика по пустому месту» и «Тип / шаблон» гекса (с пометкой
   «(свой)»). Гексы карты **ссылаются** на тип: измените эффекты здесь — после сохранения они изменятся на всех картах.

## Экспорт и импорт (v0.20.0)

**Экспорт** — выберите объект → **«Экспорт…»**:

- **«Объект .json»** — один файл. Если объекту нужны другие ваши объекты (юниту — навыки, карте — свои типы гексов), окно
  предупредит: файл **не самодостаточен**, в другой установке их не будет.
- **«Пакет .hxp»** — отметьте объекты; всё, что им нужно, добавится само (такие флажки нельзя снять). Сверху — название
  пакета. Встроенные объекты не копируются: они есть в каждой установке.
- Файлы ложатся в папку **exports** пользовательского каталога; «Папка экспорта» открывает её.

**Импорт** — **«Импорт…»** → путь к файлу (или просто имя файла из папки экспорта, или «Обзор…») → **«Показать»**:

1. Предпросмотр — ничего ещё не изменено: каждый объект с ревизией и статусом — **новый**, **уже есть, без изменений**,
   **конфликт ID** или **ошибки** (с объяснением: повреждённый файл, неизвестный тип эффекта, не хватает навыка…).
   Файл с опасными путями, чужими файлами (программы, библиотеки, скрипты), неверными контрольными суммами или слишком
   большой отклоняется целиком.
2. Для каждого объекта выберите действие: **установить**, **пропустить**, **заменить (с резервной копией)** или **копией с
   новым ID** (ссылки других объектов пакета перейдут на копию). По умолчанию конфликтующие объекты пропускаются —
   ваши данные молча не заменяются.
3. **«Установить»** — всё выбранное проверяется вместе и сохраняется целиком; при любой ошибке хранилище возвращается в
   исходное состояние. Резервные копии — в `backups`, копия пакета и запись об установке — в `packs`, журнал — в
   `logs/content.log`.

Пределы безопасности (размер пакета, число файлов, «стоимость» навыка) можно понизить файлом `limits.json` в
пользовательском каталоге — см. `docs/CONTENT_FORMAT.md`.

## Типы урона и сопротивления (v0.21.0)

- **Тип урона** выбирается списком: у обычной атаки юнита («Тип урона обычной атаки»), у эффекта урона навыка, у
  периодического урона и урона гекса. Встроенные: физический (колющий, режущий, дробящий), магический, чистый. Свои типы —
  в «Механиках» (v0.23.0).
- **Область обычной атаки**: 0 — только цель; 1–3 — все враги в этом радиусе от гекса цели; галочка «Разделить силу» —
  сила делится поровну. У эффекта урона навыка — «Область: сила»: полная по каждой цели или разделить между целями удара.
- **Сопротивления** юнита (секция в редакторе юнита): «Все сопротивляемые типы», физический и его подтипы, магический —
  от −500 до +500 %. Итог для типа = все типы + семейство + подтип; под полем — что это значит («−50 % = 150 % входящего
  урона»). Свыше +100 % урон просто 0 — лечения и отражения это не даёт (их задают правила защиты). Чистый урон
  сопротивления не учитывает. Внизу — резюме «Сильные стороны / слабости».
- Обычный «танк»: «Юниты» → «＋ Создать» → «Физический» 50 → «Сохранить» — без «Механик» и формул.
- **Бафф/дебафф сопротивления**: характеристика «сопротивление (процентные пункты)», «Сопротивление к» — всем типам или
  выбранному, «Изменение» — пункты.
- В режиме «Играть» сопротивления нигде не показываются.

## Редактор юнита по секциям (v0.24.0)

Слева четыре секции: «Основное», «Атака и навыки», «Сопротивления», «Дополнительно». Открыта одна; у закрытых — строка
резюме. Название и описание всегда сверху.

**Танк за несколько шагов:** «Юниты» → «＋ Создать» → «Основное»: HP → «Сопротивления» → «Физический» 50 → «Сохранить».

**Сопротивления.** Видны «Все сопротивляемые типы», «Физический», «Магический», «Чистый» и всё, где есть значение.
«▸ подтипы» — колющий/режущий/дробящий под физическим (и подтипы магического). Свои типы — поиском (название, тег,
семейство) или «Показать все». У «Чистого» — «Особые правила (иммунитет) ▸»: численно чистый урон не ослабить.

**Особые защиты и реакции** — карточки. Щелчок раскрывает карточку на месте: резюме правила, «Изменить копию» (копия
только для этого юнита, общее правило не меняется), «✕ Убрать»; у щита — название, прочность, принимаемый урон, порядок.
«＋ Добавить правило» — поиск по шаблонам и сохранённым правилам: шаблон открывает редактор правила поверх юнита, после
«Сохранить» и «← Каталог» правило уже у юнита, а несохранённые правки юнита на месте. «＋ Щит» — новый щит.

**Дополнительно** — ID, ревизия, наборы, где используется; «Скопировать сопротивления» из другого юнита (Ctrl+Z отменяет).

**Отладка в тесте.** В «▶ Тест юнита» есть кнопка «Отладка защиты (тест)»: карточка выбранного юнита показывает все
значения защиты с пометкой «ОТЛАДКА». В обычной игре этой кнопки нет.

## Механики (v0.23.0)

«Разработчик» → **«Механики»**: первый экран — действия «Типы урона», «Правила защиты», «Профили защиты и сопротивлений»,
«Правила боя» (с v0.27.0; ссылки
на них есть и слева под «Механиками»). Числа и правила отсюда в игре не показываются.

**Свой тип урона.** «Типы урона» → «＋ Создать» → «На основе физического» / «магического» / «чистого» / «Новое семейство» →
название, цвет, значок → «Сохранить». «Подробнее ▾» — ID, семейство (подтип считается слоями «все типы + семейство +
подтип»), стратегия (только у семейства: учитывает R или обходит R; название типа на расчёт не влияет), теги (для фильтра
правил защиты). Справа — как считается тип и кто его использует. Тип сам появляется во всех списках типов урона.

**Сразу из списка** (с v0.26.0). В любом списке «Тип урона» (навык, обычная атака, эффект гекса, правило защиты) последний
пункт — **«＋ Новый тип урона…»**: выбрать основу → настроить → «Сохранить» → «← Назад» — новый тип уже выбран в том
поле, откуда вы пришли, остальные несохранённые правки на месте. Флажок **«Категория: элемент»** помечает свой тип как
элемент: в списках он подписан «Огонь · элемент (свой)» и стоит в группе своего семейства. Отношения элементов игра не
задаёт — тип считается как его семейство. Списки сами обновляются при сохранении, переименовании и архивации — даже в уже
открытом редакторе; в каждом поле предлагаются только подходящие типы (например, «сопротивление к» не предлагает
«Чистый»).

**Набор сопротивлений.** «Наборы сопротивлений» → «＋ Создать» → «На основе набора» (необязательно) → значения в процентах →
«Сохранить». Строки показывают, что из основы, а что своё; «↺ Убрать своё значение». Встроенные примеры — «Бронированный»,
«Слаб к колющему».

**Наборы у юнита.** В «Сопротивлениях» редактора юнита: «Набор сопротивлений» → «＋ Применить набор». Значения набора —
основа; своё число в строке перекрывает его (и 0 тоже), «↺ Вернуть значение набора» убирает своё. Несколько наборов —
более поздний перекрывает ранний. «Сохранить как набор» — текущая защита юнита новым набором для других.

**«Проверить на ударе»** (в редакторах правила, типа урона и юнита): «Проверить на ударе ▾» → цель, тип, сила D0, пробитие,
здоровье цели, сколько врагов и союзников рядом → «▶ Проверить». Отчёт — по стадиям с точными числами, причины по каждому
правилу («R после пробития = 250 %, порог 300 % не достигнут») и для правила — «С правилом / Без правила». Проверяются
несохранённые правки; библиотека, матч и файлы не меняются; после каждой правки отчёт пересчитывается.

## Защита A и правила боя (v0.27.0)

**Защита A — не процент.** Сопротивление R (проценты) и защита A (очки) — разные числа и стоят в одной строке таблицы:
«R, % | A». Юнит → «Сопротивления и защита» → строка «Физический» → A = 100: удар после сопротивления уменьшается вдвое
(при K = 100). Чем больше A, тем меньше прибавка от каждого следующего очка. Итог для типа = A всех типов + семейства +
подтипа; подсказка под строкой говорит, откуда значение (своё или из профиля) и чему равен итог. «↺ Вернуть защиту A
набора» убирает своё значение. Чистый урон защиту A не учитывает; «25 %» в поле A не принимается — для процентов есть R.

**Профили** («Механики» → «Профили защиты и сопротивлений») хранят R и A вместе; юнит применяет профиль ссылкой, свои
значения перекрывают профиль по ключу. «Сохранить как набор» и «Копировать защиту» переносят R и A.

**Пробитие A** — в «Атака и навыки» юнита (обычная атака) и в «Дополнительно» эффекта урона навыка: сначала вычитаются очки,
затем не учитывается доля оставшейся A в процентах. Пробитие R работает отдельно. Бафф/дебафф «защита A (очки)» с полем
«Защита A против» меняет A на время действия.

**Правила боя** («Механики» → «Правила боя» → «＋ Создать»): «K защиты» — урон × K / (K + A), при A = K вдвое меньше
(встроенное значение 100); «＋ Свой K для семейства» — например, магическому 200. Справа — таблица «A 100 → ×0,5» и
«Проверить на ударе» с несохранённым K. Карта выбирает правила в редакторе карт («Карта» → «Правила боя»): новая карта —
«Стандартные правила боя», старая без выбора — «Совместимые правила (старые карты)».

**«Проверить на ударе»** показывает стадию «Защита: A = 100, после пробития A = 50, K = 100 → ×0,667 → 33,33» и имеет поля
«Пробитие защиты A» (очки и %) и «Правила боя (K)». В игре A не показывается; временная защита видна только словом «броня».

## Особенности: пассивы (v0.28.0)

Юнит → секция **«Особенности»** → «Шаблон пассива» → «＋ Добавить пассив». Пассив — постоянная особенность этого юнита:
действует всё время, пока юнит жив, без кнопки и слота навыка; другие юниты не меняются. Шаблоны:

- **усилить исходящий урон** — «+50 % огня»: удар 20 становится 30 до защиты цели (обычная атака и навыки);
- **снизить получаемый урон** — «−25 % физического»: остаток 40 после сопротивления, защиты A и плоского снижения
  становится 30. Это не сопротивление: R меняет само сопротивление, пассив умножает то, что осталось;
- **изменить характеристику, % / на число** — сила атаки, здоровье, скорость движения, темп атак: сначала % от базы, потом
  число (10 × 1,1 + 5 = 16);
- **сопротивление ± п.п.**, **защита A ± очки / %** — меняют выбранный слой (все типы, семейство или тип);
- **правило защиты** — подключает сохранённое правило как постоянную особенность.

У открытой карточки — только её поля: название, тип урона (тип или семейство с подтипами; «＋ Новый тип урона…»),
значение с допустимым диапазоном, «Только пока здоровье ниже, %» (0 — всегда), «Группа суммирования» — проценты одной
группы складываются (+50 % и +20 % = +70 %), разных групп перемножаются; итог урона никогда не меньше 0. «✕ Убрать
пассив» — убрать; Ctrl+Z — вернуть.

Справа **«Откуда взялось»**: «Сила атаки: 20 → 22 (+10 % · пассив «Матёрый»)», группы урона с итоговым множителем и
источниками. «В бою» показывает числа уже с пассивами. **«Проверить на ударе»** → «Атакующий»: «этот юнит бьёт пустую
цель» (проверка его исходящих пассивов без сохранения) или любой юнит библиотеки; отчёт показывает стадии «Пассивы
атакующего» и «Пассивы цели». В игре пассивы не показываются числами.

## Происхождение и теги (v0.29.0)

«Разработчик» → **«Происхождение и теги»** → «Дерево видов» или «Теги».

**Дерево видов.** «＋ Создать» → название → «Родитель» (или корень) → «＋ Добавить эффект». Пример: «Зверь» → «Волк» →
«Лунный волк» (+5 % ловкости). Юнит «Лунного волка» считается и волком, и зверем; эффекты предков действуют один раз.
У эффекта есть «Ключ эффекта»: эффект потомка с тем же ключом **заменяет** эффект предка, **отключает** его или
**действует вместе** с ним. Справа — линия вида, итоговые эффекты с источниками, потомки и юниты. Родителем нельзя выбрать
потомка — цикл невозможен.

**Теги.** «＋ Создать» → категория → эффекты (можно без эффектов — тогда это просто метка) → «Совместимость»: группа
взаимоисключения («Здоров» / «Ранен»: ошибка, последний или старший по приоритету), повтор (один раз или складывается до N),
«Только для видов», «Нужен» / «Несовместим» с другим тегом. После сохранения тег меняет всех своих юнитов.

**Вожак стаи.** Тег «Вожак» → эффект «за каждого подходящего союзника» → «Считать союзников вида: Волк и потомки», «Только
той же стаи», «Считать и себя» — выкл., +3 % силы атаки. У юнитов стаи — одинаковое поле «Стая (packId)». В бою вожак с
четырьмя волками своей стаи получает +12 %; бонус пересчитывается при появлении и гибели волков.

**Юнит → «Особенности»**: «Вид», теги (● действует / ○ не действует — с причиной), «＋ Добавить тег», «Стая», своя база
характеристик (например, «Ловкость»), пассивы. «Откуда взялось» показывает источник каждого изменения. Свои
характеристики — «Механики» → «Характеристики»: единица, база, диапазон, знаки; они меняются пассивами и тегами, но на бой
не влияют, пока их не читает механика.

## Направление и криты (v0.30.0)

«Механики» → **«Правила боя»** → набор → блоки «Направление и внезапность» и «Критические удары». Новый набор создаётся с
выключенными бонусами — включите их флажками; встроенные «Стандартные правила боя» (новые карты) включают оба,
«Совместимые правила (старые карты)» — ни одного, поэтому старые карты играют как раньше.

**Внезапный удар по стороне цели.** Сторона считается от взгляда **цели**, а не от экрана: спереди, передние фланги,
задние фланги, сзади (по умолчанию 0 / 25 / 75 / 100 %). Пока выключено «Разные левый и правый фланги», правка «передних
флангов» или «задних флангов» меняет обе стороны сразу; с флажком — все шесть полей отдельно. Значение вне 0…100 %
не принимается и объясняется. «Множитель внезапного удара» — ×1,5 по умолчанию. Удары поверхности, периодический урон,
отражения и удары без атакующего внезапными не бывают.

**Криты и сверхкриты.** Шанс — в процентных пунктах и складывается: «Базовый шанс всех атакующих» правил + «Шанс крита»
юнита («Атака и навыки») + пассивы и теги «шанс крита ± п.п.». До 100 — шанс крита; 100 — крит всегда; сверх 100 — шанс
сверхкрита (125 → крит 75 %, сверхкрит 25 %); 200 и больше — сверхкрит всегда, лишнее пока не даёт эффекта. Справа —
таблица «Вероятности крита». Внезапность и крит независимы, множители перемножаются: 20 × 1,5 × 2,25 = 67,5 до защиты.
Обычная атака может критовать всегда, навык — только с отметкой «Может быть критическим» в «Дополнительно» эффекта урона
(там же: «Бросок крита в серии» и «Бросок крита по целям области»). Шаблоны «невосприимчив к критам» и «невосприимчив к
внезапным ударам» — в «Особенностях» юнита, у вида или тега.

**«Проверить на ударе»**: «Сторона цели» и «Исход (только для проверки)» — «по броску» или заданный («внезапный
сверхкрит»), чтобы увидеть стадии «Внезапность: задний правый фланг → 75 % → бросок → да, ×1.5» и «Крит: шанс 125 п.п.
(крит 75 %, сверхкрит 25 %) → … → сверхкрит ×2.25». Бросок воспроизводим: тот же удар даёт тот же результат, пауза и
перерисовка ничего не бросают. Карта выбирает набор правил в редакторе карт; в режиме «Играть» шансы не показываются.

## Исследование: вход, выход и правило победы (v0.38.0)

«Сценарии» → «Создать» → выберите карту → карточка **«Исследование»**. Отряд входит в отмеченном месте и пробивается к выходу;
побеждать всех врагов не нужно, если это не выбрано задачей.

- **«Исследование — шаги»** — список шагов с отметками ✓: карта, вход, выход (достижим от входа), отряд, враги и охранники
  (необязательно), правило победы. Вход сразу заполняется гексами выставления карты — их можно поменять.
- **Кисти** «Ставить: враги», «Вход», «Выход»: с кистью «Вход» или «Выход» щелчок по гексу добавляет его к области, повторный
  щелчок убирает. На поле вход — зелёный, выход — голубой. Врага на гекс входа поставить нельзя.
- **«Правило победы»**: «Победа, когда» — ключевой юнит дошёл до выхода (выберите «Ключевой юнит» — карточку отряда; его
  гибель — поражение), любой выживший дошёл, все обязательные дошли (флажки «обязателен» у карточек; гибель любого из них —
  поражение). «Дополнительная задача»: нет, победить отмеченных врагов (выберите врага на поле и отметьте «Цель задачи» —
  он станет оранжевым), зачистить карту.
- Охранники по пути — враги с «Поведение: охранник» (см. «Оборона»).

Проверка не пустит в бой исследование без входа или выхода, с выходом за стеной (нет пути по проходимым гексам), с врагом на
входе, с задачей «отмеченные» без отмеченных и с «все обязательные» без обязательных. В бою вход и выход подсвечены, слева —
«Исследование · N с · осталось: …»; когда кто-то дошёл, а задача не выполнена, игра пишет, что осталось.

## Оборона: объекты, источники и простой ИИ (v0.37.0)

«Сценарии» → «Создать» → карточка **«Оборона»** → выберите карту. Базы игрока не нужно: враги выходят из баз врага и зон
появления карты (или идут по её маршрутам) и нападают на ваш отряд и объекты миссии.

- **«Цель обороны»** — три шаблона одной кнопкой: «Выстоять время» (60 с, гибель отряда — поражение), «Защитить объект»
  (победа — все волны отбиты, группы идут к объектам, кисть «объекты» включается сама), «Отбить все волны». Шаблон добавляет
  первую волну, если её нет, и отменяется одним Ctrl+Z. Дальше — поля: «Выстоять, с» (0 — до конца волн), «Объекты» (все
  критические должны уцелеть / хотя бы один), «Гибель всего отряда — поражение».
- **«Объекты миссии»** — кисть «Ставить: объекты», щелчок по свободному гексу ставит золотой столб; щелчок по объекту
  выбирает его: «Название объекта», «Здоровье», «Критический — его потеря = поражение», «Убрать объект». Объект не ходит, не
  бьёт и не получает приказов, но его можно атаковать.
- **Группы волны** — «Откуда» (база врага, зона карты или «по маршруту …»), «Поведение» (к объекту; атаковать юнитов; сначала
  юниты, потом объект; сначала объект, потом юниты; охранник), «Замечает за, гексов» (0 — всю карту).
- **Враги на карте** — кисть «Ставить: враги»; у выбранного врага — «Поведение» и радиус охраны или дальность. Охранник
  годится и для обычного боя: бьёт только тех, кто подошёл к его гексу, и возвращается на пост.
- **«Дополнительно ▾»** под поведением — редкие настройки: «Цель — сначала» (ближайший / меньше здоровья), «Пересматривать
  цель раз в, с», «Бить того, кто держит блоком».

«Сценарий словами» — объекты, источники с числом врагов и поведение групп. Проверка не пустит в бой оборону без окончания (ни
времени, ни волн), группу с несуществующим источником и объект вне проходимого гекса. В бою слева — «Выстоять: 10 из 20 с»
и здоровье каждого объекта.

## Tower Defense: волны и базы (v0.36.0)

«Сценарии» → «Создать» → карточка **«Tower Defense»** → выберите карту с маршрутами врагов (их рисуют в редакторе карт,
«〰 Маршруты»). На поле сценария видны красные линии маршрутов.

- **«Базы игрока»** — у каждой базы карты свои жизни (по умолчанию 20) и флажок «критическая»: падение критической базы —
  поражение. Враг, дошедший до конца своего маршрута, снимает 1 жизнь **только у своей** базы и исчезает.
- **«Волны»** — список волн с числом врагов (считается само); «＋ Волна» добавляет волну с группой из 5 врагов на первом маршруте.
  Щёлкните волну, чтобы открыть её карточку: название, «Старт» (после окончания предыдущей / в секунду боя / после начала
  предыдущей), задержка, «Включена», «Копия», ↑ ↓, «Удалить».
- **Группы волны** — по какой линии и кто идёт: «Маршрут», «Юнит врага», «Врагов», «Первый через, с», «Интервал, с» (0 — все
  сразу: занятый вход пропустит их по одному, без наложений), «Сдвиг группы, с» (согласовать несколько маршрутов), «включена»,
  «Убрать группу»; «＋ Группа». В одной волне — сколько угодно линий; у одной линии — группы разных волн.
- **«Поражение, когда»** (в «Правилах боя») — любая критическая база без жизней / все базы / общий запас жизней.

«Сценарий словами» показывает суммы по маршрутам и расписание: «1. «Волна 1» — на 1 с боя: 2 × «Оперативник» по «Маршрут 1» с
0 с каждые 1 с; 1 × … по «Петля» с 2 с · всего 3». Если маршрут группы удалён на карте или требует проверки, «Проверка» называет
волну и группу, и сценарий не запускается. В бою слева — «Волна 1 из 3 · впереди врагов · на поле» и жизни каждой базы.

## Маршруты врагов (v0.35.0)

Редактор карт → **«〰 Маршруты»** в верхней строке. Маршрут — красная линия, по которой враги пойдут от базы врага к базе
игрока (волны Tower Defense будут ссылаться на неё — v0.36.0).

1. **Базы.** Гексы типа «База врага» и «База игрока»; у выбранного гекса базы — «Номер базы» (1…9) и её название. Гексы одной
   стороны с одним номером — одна база, баз каждой стороны может быть несколько.
2. **Новая линия.** В режиме «Маршруты» **ЛКМ по гексу базы врага** — появляется оранжевый черновик. Дальше просто **ведите
   курсор** по соседним гексам — каждый пройденный гекс добавляется сам, кликать по каждому не нужно. Быстрое движение мыши
   добавляет только соседние гексы по пути курсора, без прыжков. Возвращаться и проходить гекс повторно можно: оба посещения
   сохраняются по порядку; пересекать чужие линии тоже можно.
3. **Завершение.** Курсор входит на гекс базы игрока — маршрут сохранён в карте («Маршрут 1», Ctrl+Z — отменить).
4. **Ошибки.** Пустое место, препятствие или край области останавливают черновик: верная часть остаётся, место ошибки —
   красное, причина — в панели («гекс (5,2) непроходим»). Обойдите его другим путём.
5. **Backspace** или «⌫ Последний сегмент» — убрать последний гекс черновика; **Esc** или **ПКМ** — отменить черновик (готовые
   линии не трогаются).

Слева — список линий (⚠ — требует проверки) и карточка выбранной: название, откуда → куда, число гексов и повторов, «Включён»,
проблемы с номером шага и гексом, «Перерисовать» (новая линия заменит старую, ID и название останутся), «Копия», «Удалить».
ЛКМ по линии на поле тоже выбирает её. «Проверить маршруты» — одна строка на маршрут в сообщениях. Если удалить гекс под
маршрутом, маршрут не пропадёт: он станет «требует проверки», а гекс подсветится красным в карточке.

Проверить ходьбой: «▶ Тест карты» → в панели отладки «Маршруты врагов» → «Показать линии маршрутов» (в игре линии по
умолчанию скрыты) и «▶ Враг: «название»» — враг встаёт в начало линии и идёт по ней шаг за шагом; занятый гекс впереди он
ждёт, обходов и перескоков на другие линии нет.

## Сценарии: обычный бой (v0.34.0)

Каталог → **«Сценарии»** (сразу после «Карт») → «Создать». Сценарий — что играть: карта, тип, враги, которые уже стоят на
карте, отряд игрока и правила боя. Один экран, разделы сверху вниз — в порядке работы:

1. **«Тип сценария»** — четыре карточки: «Обычный бой», Tower Defense (v0.36.0), «Оборона» (v0.37.0) и «Исследование»
   (v0.38.0).
2. **«Карта»** — любая карта библиотеки; «✎ Открыть карту в редакторе» — поправить гексы выставления или препятствия
   (карта общая для всех сценариев с ней; встроенная сохранится копией, и сценарий перейдёт на копию).
3. **«Враги на карте»** — посередине сама карта. **ЛКМ по свободному гексу** ставит врага юнита из списка «Ставить» и сразу
   выбирает его; **ЛКМ по врагу** выбирает; **ПКМ** убирает; **Q / E** или «↶ / ↷ Повернуть» поворачивают выбранного (без
   выбора — взгляд следующих врагов); Delete — убрать, Esc — снять выбор. Список «Юнит врага» меняет выбранного. На
   препятствие, в пустоту и за край врага поставить нельзя — внизу сказано почему. Если после смены карты враг оказался вне
   проходимого гекса, он серый на красном; кнопка «Убрать врагов вне проходимых гексов» убирает их одним действием (Ctrl+Z
   вернёт).
4. **«Отряд игрока»** — карточки нижней панели в бою, от 1 до 5, по порядку: «✕» убирает, «Добавить юнит» + «＋ В отряд».
5. **«Правила боя»** — правила урона и критов (или «как на карте»), «Подготовка на паузе», «Автоатака юнитов», «Блок»,
   «Ограничение времени, с» (0 — нет).

Справа — **«Сценарий словами»**: тип, карта, враги («3 × «Оперативник»»), отряд, подготовка и цели («Победа: все враги (3)
побеждены. Поражение: все ваши юниты погибли и в резерве никого.»), ниже — «Проверка». Сценарий с ошибкой (нет врагов,
враг на препятствии, юнита нет в библиотеке, у карты нет гексов выставления) не сохраняется как готовый, не запускается и не
появляется в меню; «▶ Тест сценария» играет временную копию.

В бою сценария: старт — **«Подготовка»** на паузе (баннер «ПОДГОТОВКА · пробел — начать бой»): выставьте карточки на зелёные
гексы, задайте маршруты и взгляд; ничего не идёт, пока не нажата «Начать бой» (пробел). Слева — цели и сколько врагов осталось.
Победа — последний враг побеждён; поражение — все ваши юниты погибли и выставить больше некого (или вышло время). Итог
останавливает бой. Сценарии без ошибок выбираются в стартовом меню в списке «Сценарий»; встроенный пример — «Учебный бой».

## Блок (v0.33.0)

Юнит → «Атака и навыки» → **«Блок»** — одно число: сколько двигающихся врагов юнит удерживает одновременно, пока **стоит**.
0 — никого (так у всех юнитов по умолчанию и у сделанных раньше), 1 — одного, 3 — трёх. Удержанный враг остаётся на своём
гексе рядом и не идёт дальше, пока блок не снят: блокер ушёл (получил приказ движения), погиб, враг оказался не рядом или
бафф/дебафф уменьшил блок (отпускаются самые новые). У врага — только один блокер. Блок не защищает и не наносит урон;
атаки работают как раньше (лучник с блоком 0 стреляет).

Блок — характеристика «Блок» общего реестра («Механики» → «Характеристики»): пассивы и теги меняют его («Щит»: +1 блок),
в навыке есть бафф/дебафф «блок» (целые слоты). Итог виден в поле («Блок (итог 3)») и в строке «В бою». В игре над
удержанным врагом — слово «блок».

## Базовая атака (v0.32.0)

Юнит может бить сам — **автоатака**. Она бьёт только врагов в **своей области** (своей, а не навыка), область поворачивается
вместе со взглядом юнита; юнит сам не поворачивается к врагу и не идёт за ним. Частота — «скорость атак» юнита (3 — три удара в
секунду), сила — доля «силы атаки».

**Область.** «Механики» → «Базовые атаки» → «＋ Создать»: гекс-поле с юнитом в центре. Щелчок по гексу добавляет его в
область или убирает; «↶ Повернуть» / «Повернуть ↷» (Q / E) поворачивают юнита — область поворачивается с ним, сохранённая
область та же. Справа — словами: «Область: 2 гекс. (перед, второй перед)». «Кого бить» — ближайшего, слабейшего или по
порядку гексов; «Целей за удар» 1–6; «Сила удара, % силы атаки»; «Тип урона» — свой (новые типы появляются сразу) или как
у обычной атаки. «Дополнительно ▾»: криты, внезапность, «Бьёт и в движении».

**Юнит.** «Атака и навыки» → «Автоатака включена», «Базовая атака» (встроенная — «Передний гекс»). «В бою» показывает:
«Базовая атака: 3 удар/с · передний гекс · 1 враг · 10 урона до защиты».

**Карта.** Автоатака действует только на картах с флажком «Автоатака юнитов» (редактор карт → «Карта»). Старые карты и
прототип — без неё, поэтому прежние бои не меняются. Явный приказ атаки (стрелка на врага) по-прежнему главнее.

## Полный редактор части 6 (v0.31.0)

**Стороны на рисунке.** «Правила боя» → «Направление и внезапность»: шестиугольник — цель в центре смотрит вверх, у каждой
стороны её шанс, чем краснее — тем вероятнее внезапность. Щелчок по стороне → поле «<сторона>, %» (в симметричном пресете
меняет и зеркальную) и «▶ Тест атаки с этой стороны» — справа открывается «Проверить на ударе» с атакующим с этой стороны.
«Только удар с соседнего гекса» — бонус лишь для ближнего боя. У атакующего шанс можно поднять шаблоном «шанс внезапного
удара ± п.п.» (пассив, вид, тег).

**Криты на тысяче бросков.** «Критические удары» → «Шанс для проверки, п.п.» → «▶ Проверить 1000 бросков»: «1000 бросков при
C 125 п.п.: обычный 0, крит 758, сверхкрит 242 (по формуле 0 / 750 / 250)». Броски те же, что в бою, — результат одинаков
при каждом нажатии.

**Тестовый стенд.** В любом «Проверить на ударе»: «Seed бросков», «Проверить 100 событий» (100 ударов по броскам — сколько
внезапных, критов, сверхкритов, потеря HP мин / сред / макс), «Сбросить тест». Определения при этом не меняются.

**Тег многим юнитам.** Редактор тега → справа «Юниты с этим тегом» → «Назначить юниту» → «＋ В список назначения» (сколько
нужно) → «Назначить тег (N)». Тег должен быть сохранён; каждый юнит проверяется заранее — если хоть одному тег нельзя
(не тот вид, несовместимый тег), не меняется ни один, а сообщение называет причину.

**Сводка юнита.** Заголовок «Особенности» показывает «вид «Волк» · тегов: 3 · активных эффектов: 4»; подробности — в
«Откуда взялось». В игре над целью коротко видно «Крит!», «Сверхкрит!» или «Внезапно!» — без шансов и сторон.

## Правила защиты (v0.22.0)

Категория **«Правила защиты»**: правило — «**когда** → **от какого урона** → **при условии** → **что сделать**». Одно правило
можно подключить к любому числу юнитов (по ссылке); изменение правила после сохранения действует на всех.

1. «＋ Создать» → в блоке «Шаблон» выбрать: «Иммунитет», «Поглощать урон», «Поглощать и лечиться», «Отражать часть урона»,
   «Ответный удар», «Щит», «Плоское снижение», «Предел урона», «Вампиризм», «Иммунитет к дебаффам», «Сложная реакция» →
   «Применить шаблон» (заменяет условия и реакции; Ctrl+Z возвращает).
2. **Когда**: «получен удар», «потеряно HP или прочность щита», «нанесён урон своим ударом», «накладывается статус» —
   список реакций зависит от этого выбора. **От какого урона**: тип, семейство (с подтипами) или «любой тип (и чистый)».
3. **Условия** включаются галочками: «Только при сопротивлении не ниже порога» (эффективное R после пробития; у чистого
   урона R нет), «Только при здоровье ниже порога».
4. **Что сделать**: поля каждой реакции; доли — в процентах («25» = 25 % силы удара). Для отражения — «Кому»: атакующему
   или «вокруг себя» (радиус, фильтр врагов/союзников, каждой цели полностью или поровну).
5. «Дополнительно ▾»: приоритет (меньше — раньше; следующее правило получает только остаток силы удара), перезарядка,
   лимит срабатываний, тег типа, «срабатывать при иммунитете», тип ответного урона, «включая свой гекс».
6. Справа — **правило словами** и «Поглощение и отражение: N % из 100 %» (больше 100 % — ошибка). На поле: синий —
   защитник, красный — атакующий, оранжевый — куда уходит отражение.

Пример (встроенный, «Огненная регенерация и круговое отражение (пример)»): при попадании огнём и R огня ≥ 300 % — 25 %
силы удара лечат, 75 % уходят каждому врагу на шести соседних гексах. Удар 40 → лечение 10, по 30 каждому соседнему врагу,
HP защитник не теряет. Само R = 300 % (без правила) даёт только 0 урона.

**В редакторе юнита — «Особые защиты и реакции»**: «Добавить правило: поиск» → выбрать → «＋ Добавить правило»; под каждым
правилом — его резюме, ✕ — убрать у юнита (правило остаётся в библиотеке). **Щиты**: «＋ Добавить щит», название,
прочность (HP), «Принимает» (любой урон, тип или семейство), порядок. Щит принимает уже рассчитанный урон до HP, в бою
начинается полным; чистый урон он тоже принимает.

В бою над юнитом — только «невосприимчив» или «щит», без чисел.
